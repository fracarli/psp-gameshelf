# Project language and publication rules

- Write all project documentation, release instructions, code comments, developer
  tools and public GitHub content in English.
- English is the default application language. PSP UI translations may follow
  the console system-language setting; unsupported languages fall back to English.
- Keep translated strings in the localization table rather than hard-coding
  non-English UI text in the application logic.
- Preserve upstream source and license notices in their original form.
- Only publish files belonging to this repository. Never stage memory-card
  contents, ROMs, BIOS files, saves, downloaded artwork, personal backups or
  unrelated Desktop files.
- Keep hardware-confirmed packages in releases/ and unconfirmed builds in
  candidates/. Do not overwrite archived, hardware-confirmed executables.
