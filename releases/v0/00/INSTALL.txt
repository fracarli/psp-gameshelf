VERSION 0 - stable baseline, previously v0.51.0

This build avoids the firmware HOME popup crash in integrated TempGBA.
1. Copy EBOOT.PBP to PSP/GAME/GAMESHELF/.
2. Merge the supplied TempGBA directory into PSP/GAME/GAMESHELF/TempGBA/.
3. Exit GBA games through TempGBA's internal Quit/Exit menu.

Preserve existing ROMs, BIOS files, saves and states when merging directories.
The HOME popup is intentionally disabled to avoid the known crash.
The GBA BIOS is not included; provide your own required BIOS file.
