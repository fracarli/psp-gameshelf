PSP GameShelf v0.47.0

Copy these files to the memory stick:

1. EBOOT.PBP -> PSP/GAME/GAMESHELF/EBOOT.PBP
2. TempGBA/EBOOT.PBP -> PSP/GAME/GAMESHELF/TempGBA/EBOOT.PBP

Keep the existing support files in PSP/GAME/GAMESHELF/TempGBA/:
dir.ini, gba_bios.bin, tempgba_me.prx, cp_fix_gbk.prx and exception.prx.
GameShelf will create/update the roms, save, state and other folders when a
GBA title is selected.
