PSP GameShelf 1.03 - full-screen backgrounds confirmed on PSP

1. Preserve existing adapted emulators, ROMs, BIOS files and saves.
2. Replace PSP/GAME/GAMESHELF/EBOOT.PBP with the supplied EBOOT.PBP.
3. Prepare covers and backgrounds on your computer:
   python3 tools/fetch_boxart.py --sd-root /Volumes/SD-FAT32 --platform nes --platform gba
   Existing PNG covers are reused to create Game.pic1.png at 480x272 pixels.
4. Open GameShelf 1.03 and press X to update game entries.
5. Open Game > Memory Stick and highlight a game. The XMB controls when
   the embedded PIC1 background appears.

The background enlarges and centrally crops the cover without stretching.
It is darkened slightly to keep XMB text readable. Square icons are retained.
An entry without a valid background keeps its icon and remains launchable.
No video or music is included.

To restore 1.02, install releases/v1/02/EBOOT.PBP and regenerate entries.
This package is a visual update; GBA save isolation is introduced in the
separate 1.04 candidate, which requires a paired runtime update.
