PSP GameShelf 1.00 - NES and GBA direct launch confirmed on PSP

Tested target: PSP-3004, firmware 6.61 with PRO-C enabled.
Run FastRecovery after a full shutdown if required.

1. Back up your existing PSP/GAME/GAMESHELF directory.
2. Copy EBOOT.PBP to PSP/GAME/GAMESHELF/EBOOT.PBP.
3. Merge TempGBA/ into PSP/GAME/GAMESHELF/TempGBA/.
   Preserve existing ROMs, BIOS files, saves and states.
4. Keep the adapted NesterJ at PSP/GAME/Nester_AoEX_R3/EBOOT.PBP.
   If needed, copy NesterJ-EBOOT.PBP there as EBOOT.PBP after backing up
   the previous executable.
5. Keep the original BIOS and support modules in PSP/GAME/TempGBA4PSP-Mod/.
6. NES ROMs belong in Nester_AoEX_R3/roms; GBA ROMs belong in
   TempGBA4PSP-Mod/roms. Up to 32 ROMs are scanned per system.
7. Open GameShelf, press X, review the summary and press X to return home.
8. Open Game > Memory Stick and launch an [NES] or [GBA] game directly.
   Exit GBA through its internal Quit/Exit menu, not the firmware HOME popup.

Version 1.00 uses the common GameShelf icon. Emulators remain shared.
The staged GBA ROM is named game.gba; check save behavior before regular use.
Games, BIOS files and save data are not included in this package.

To restore the baseline, copy releases/v0/00 over GAMESHELF, preserving user data.
Generated GSH_GBA_* and GSH_NES_* directories contain the individual game entries.
Remove only those directories to remove entries; keep the emulator directories.
