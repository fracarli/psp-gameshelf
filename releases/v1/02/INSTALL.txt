PSP GameShelf 1.02 - square icons confirmed on PSP

1. Keep existing adapted emulators, ROMs, BIOS files and saves.
2. Replace PSP/GAME/GAMESHELF/EBOOT.PBP with the supplied EBOOT.PBP.
3. Prepare square cover textures on your computer:
   python3 tools/fetch_boxart.py --sd-root /Volumes/SD-FAT32 --platform nes --platform gba
   Existing PNG covers are reused to create the dedicated *.xmb.gsh textures.
4. Open GameShelf 1.02 on the PSP and press X to update game entries.
5. Return home and open Game > Memory Stick.

Icons are square 80x80 PNGs without a rectangular frame or side bars.
Square covers remain complete. Rectangular covers are cropped centrally
without stretching. Legacy .gsh textures remain available as a fallback.
Emulator behavior and save data are not changed by this visual update.

To restore 1.01, install releases/v1/01/EBOOT.PBP and regenerate entries.
