PSP GameShelf 1.01 - XMB cover icons confirmed on PSP

Update from 1.00:
1. Back up PSP/GAME/GAMESHELF/EBOOT.PBP.
2. Replace it with this package's EBOOT.PBP.
3. Keep the existing adapted emulators, ROMs, BIOS files and saves.
4. On your computer, prepare available covers:
   python3 tools/fetch_boxart.py --sd-root /Volumes/SD-FAT32 --platform nes --platform gba
5. Open GameShelf 1.01 on the PSP and press X to update existing game entries.
6. Press X again to return home, then open Game > Memory Stick.

Version 1.01 displays a cover fitted inside a 144x80 PNG icon.
Cover textures are read from PSP/GAME/GAMESHELF/boxart/nes or gba.
Match the ROM basename, for example Game.gsh for Game.gba.
Missing or invalid artwork falls back to the common GameShelf icon.
ROM hacks may require manually provided covers.

For a first installation, install 1.00 before updating the main EBOOT.
To restore 1.00, replace the main EBOOT, remove generated GSH_GBA_* and
GSH_NES_* entries, and regenerate them with 1.00.
Square borderless icons are available in 1.02 and later.
